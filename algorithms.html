What it does Checks elements one by one from the beginning to the end until the target is found or the list ends. Searches for a target in a sorted array by repeatedly dividing the search range in half. Sorts an array by repeatedly comparing adjacent elements and swapping them if they are in the wrong order. Sorts an array by dividing it into halves, sorting each half, and then merging the sorted halves. Sorts an array by building a sorted prefix one element at a time and inserting each new element into its correct position.
Pseudo code 
LinearSearch(arr, target):
  for i from 0 to length(arr) - 1:
      if arr[i] == target:
          return i
  return -1
 
BinarySearch(arr, target):
  left = 0
  right = length(arr) - 1

  while left <= right:
      mid = (left + right) // 2

      if arr[mid] == target:
          return mid
      else if arr[mid] < target:
          left = mid + 1
      else:
          right = mid - 1

  return -1
 
BubbleSort(arr):
  n = length(arr)

  for i from 0 to n - 1:
      swapped = false

      for j from 0 to n - i - 2:
          if arr[j] > arr[j + 1]:
              swap arr[j], arr[j + 1]
              swapped = true

      if swapped == false:
          break

  return arr

Merge(left, right):
  result = []

  while left and right are not empty:
      if left[0] <= right[0]:
          append left[0] to result
          remove left[0]
      else:
          append right[0] to result
          remove right[0]

  return result

Summary of How to Use

  • Linear Search: use for unsorted or very small data when simplicity matters.
  • Binary Search: use when the data is already sorted and you need fast lookup.
  • Bubble Sort: use mainly for learning or very small datasets.
  • Merge Sort: use for large datasets when stable sorting and reliable performance are important.
  • Insertion Sort: use for small or nearly sorted data, especially when the data arrives gradually.
